# Instagram Login (Clone)

Um projeto de estudo que recria a tela de login e cadastro do Instagram, com foco em praticar **HTML** e **CSS** (layout, formulários e responsividade).

## ⚠️ Aviso Importante

Este projeto **não possui nenhuma finalidade comercial ou lucrativa**. Foi desenvolvido **exclusivamente para fins educacionais**, como exercício de prática de front-end.

- Não é afiliado, endossado ou de propriedade da Meta/Instagram.
- Marcas, logotipos e nomes utilizados pertencem aos seus respectivos donos e foram usados apenas como referência visual de estudo.
- Não coleta, armazena ou processa dados reais de usuários — os formulários são estáticos e não enviam informações a nenhum servidor.

## 🚀 Sobre o Projeto

O projeto reproduz duas telas principais:

- **Login** (`index.html`) — tela inicial com formulário de acesso.
- **Cadastro** (`signup.html`) — tela de criação de conta.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estruturação semântica das páginas.
- **CSS3** — estilização, uso de variáveis (`:root`/`body`), Flexbox para layout e **Media Queries** para responsividade (mobile/tablet).

Nenhum framework, biblioteca ou dependência externa foi utilizado — apenas HTML e CSS puros.

## 📁 Estrutura do Projeto

```
├── index.html      # Página de login
├── signup.html     # Página de cadastro
├── style.css        # Estilos das páginas
└── images/          # Imagens utilizadas (logo, botões de app, etc.)
```

## ▶️ Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador. Não há necessidade de instalação ou servidor.
